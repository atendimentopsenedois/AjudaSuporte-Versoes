# AjudaSuporte — versões públicas

Este repositório é público **apenas para consulta da versão** do aplicativo AjudaSuporte. O código-fonte permanece em um repositório privado separado.

- [Manifesto de versão](./version.json)
- [Arquivo público em formato bruto](https://raw.githubusercontent.com/atendimentopsenedois/AjudaSuporte-Versoes/main/version.json)

O campo `version` deve representar a **última versão com instalador publicado e validado**, não apenas uma alteração no código. Ele será atualizado automaticamente após a publicação bem-sucedida de uma Release quando a integração estiver configurada.

Não inclua senhas, tokens, código-fonte, logs, dados de clientes ou detalhes de infraestrutura neste repositório.

**Observação:** o link de Release aponta para o repositório privado e pode exigir acesso autorizado para realizar o download.
