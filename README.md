# AjudaSuporte

Este repositório público disponibiliza **somente o instalador compilado** do AjudaSuporte e seu manifesto de versão. O código-fonte e a infraestrutura de desenvolvimento permanecem em um repositório privado.

## Baixar o programa

**[Baixar a versão mais recente (Releases)](https://github.com/atendimentopsenedois/AjudaSuporte-Versoes/releases/latest)**

Quando houver uma Release publicada, procure o arquivo `AjudaSuporte_vX.XX.exe` na seção **Assets**. O arquivo `SHA256SUMS.txt` permite verificar a integridade.

## Consultar versão pelo aplicativo

- [Manifesto público de versão](./version.json)
- [Link direto para o arquivo](https://raw.githubusercontent.com/atendimentopsenedois/AjudaSuporte-Versoes/main/version.json)

O número do manifesto só será atualizado após a publicação da Release pública pelo workflow do repositório privado. Enquanto a compilação da primeira Release não for concluída, a área de Releases poderá ficar vazia.

**Atenção:** um executável .NET compilado pode ser analisado por engenharia reversa. A ausência dos arquivos-fonte no download não equivale a proteção absoluta do código ou dos algoritmos internos. Não distribuir credenciais ou dados de clientes.
